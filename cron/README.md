# cron/ 定时任务模板

本目录存放 Argent 预置的定时任务模板。

**默认不启用**：为避免未经配置就在用户设备上静默运行定时任务，所有 cron 模板需要用户手动启用后才生效。

## 启用方式

1. 查看模板内容，确认任务描述与触发频率
2. 将模板文件复制到用户配置目录的 `cron/` 下（或按 Hermes 文档导入）
3. 在模板中填写实际的 API Key、目标群组等运行参数
4. 重启 Argent / 重新加载配置后生效

## 规范

- 每个模板为一个自包含的任务定义文件（含任务说明、调度表达式、参数占位符）
- 占位符统一使用 `<PLACEHOLDER>` 形式，避免误填真实凭据
- 模板中不得包含真实密钥、Token 或个人数据
