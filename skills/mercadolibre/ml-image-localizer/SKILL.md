# 美客多多站点图适配

## 目标
将已有一个站点的主图/附图适配到其他美客多站点，处理图片文字翻译、尺寸调整和站点规范差异，输出站点定制的 Listing 图片包。

## 触发生效条件
- 用户要在第二个站点上架同一产品（如从墨站扩展到巴站）
- 用户要求「把图适配到巴西」
- 用户需要批量转换多个站点的图片格式

## 执行流程

### 步骤 1：确认源站点与目标站点
用户指定：
- 源站点（已有图的站点）
- 目标站点（需要适配的站点）
确认两站点的图片规范差异（由本技能维护的站点规范表提供）。

### 步骤 2：提取源图
从用户美客多 Listing 或用户上传获取产品图。
列出图片清单供用户确认哪些需要适配。

### 步骤 3：处理图片文字本地化
如原图含西班牙语文字（如促销标签、功能介绍），翻译为目标站点语言：
- 墨西哥→巴西：西语→葡语
- 墨/巴→阿根廷：基本保留西语（部分本地化表达）
文字叠加风格保持与原图一致。

### 步骤 4：调整尺寸与格式
按目标站点规范输出：
- 分辨率
- 文件格式（JPG/PNG/WebP）
- 最大文件大小
- 背景色要求

### 步骤 5：输出适配图包
输出为独立文件夹 + 适配说明文档：
- 适配后的图片文件
- 每张图的原始文件名映射
- 已做的修改摘要

## 失败处理
| 错误 | 处理 |
|------|------|
| 源图文字无法提取 | 用户手动提供文字内容供翻译 |
| 目标站点规范未知 | 建议用户先验证一张，观察平台反馈 |
| 图片翻译质量低 | 建议用户手动复核关键促销文字 |

## 注意事项
- 文字本地化只做语言翻译，不做品牌/Logo 替换
- 适配后的图仍需人工审核再上传，AI 翻译可能有细微偏差
- 各站点违规政策不同，适配时需符合目标站点的具体规则
