# 美客多多店铺管理

## 目标
跨店铺、跨站点统一管理面板，支持批量数据拉取、聚合对比、快速切换和批量操作，解决多店铺卖家的信息分散问题。

## 触发生效条件
- 用户有多个美客多店铺（同站点多店 / 多站点多店）
- 用户询问「所有店铺的订单情况」
- 用户需要「批量对比各店数据」
- 用户要「给所有店做同一操作」

## 执行流程

### 步骤 1：获取全部店铺列表
```bash
ziniao-cli store list --format json
```
列出所有可用的美客多店铺环境，按站点分组。

### 步骤 2：并行或串行拉取各店概览
对每个店铺执行轻量级概览数据拉取：
- 今日订单数
- 今日销售额
- 在线 Listing 数
- Reputación 评分
- FULL 库存状态
输出聚合对比表：

| 店铺 | 站点 | 今日订单 | 今日销售额 | Reputación | 在线 Listing | 待处理 |
|------|------|----------|------------|------------|--------------|--------|
| Tienda MX | 墨西哥 | 12 | MXN 3,450 | Verde | 28 | 退货1 |
| Tienda BR | 巴西 | 8 | BRL 1,200 | Azul | 15 | — |
| Tienda AR | 阿根廷 | 3 | ARS 45,000 | Amarillo | 9 | 纠纷1 |

### 步骤 3：批量操作辅助
如用户需要对多个店铺执行相同操作，逐店执行并汇总结果：
- 批量创建货件（提供各店参数）
- 批量检查关键词排名
- 批量广告竞价调整
每店执行结果单独输出，失败不影响其他店。

### 步骤 4：聚合洞察
跨店铺分析：
- 总销售额/总订单量
- 各站点贡献占比
- 表现最佳的店铺 vs 待改进店铺
- 多店铺 Reutación 排名

### 步骤 5：输出聚合报告
标准 Markdown 格式：
```markdown
# 多店铺管理报告
日期: YYYY-MM-DD | 店铺数: X

## 总览
总销售额: [汇总]
总订单量: [汇总]
最佳店铺: [店铺名]

## 各店详情
[对比表]

## ⚠️ 跨店告警
1. [店铺名] 有待处理退货
2. [店铺名] 有纠纷
3. [店铺名] 库存不足
```

## 失败处理
| 错误 | 处理 |
|------|------|
| 部分店铺环境离线 | 标记「离线」，跳过该店 |
| 单店拉取超时 | 设置单店超时，超市跳过不阻塞其他店 |
| 无可用店铺 | 输出「未配置任何美客多店铺环境」 |

## 注意事项
- 多店铺操作频率受紫鸟店铺环境并发限制
- 批量操作涉及修改的（如广告调价、创建货件），每步都需用户确认
- 多站点语言自动切换（西语/葡语），避免混用
