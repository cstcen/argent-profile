# 美客多 AI 场景图生成

## 目标
利用 AI 图像生成能力，将产品白底图转换为拉美本地化场景图（如墨西哥客厅、巴西海滩、阿根廷咖啡馆），批量生成多尺寸适用 Listing 各位置的主图变体。

## 触发生效条件
- 用户提供产品图片或产品名称
- 用户要求「拉美风格场景图」「墨西哥风格背景」
- 用户需要批量生成多场景产品图

## 执行流程

### 步骤 1：获取产品图
如用户提供产品图片，直接使用。如用户只提供产品名，尝试：
- 从用户美客多 Listing 中提取主图
- 或者让用户上传产品白底图

### 步骤 2：确认场景风格
向用户展示可选拉美场景模板（由脚本或配置文件提供）：
- 墨西哥：暖色调客厅、传统 mercado 集市、现代公寓
- 巴西：海滩日光、热带雨林、都市夜景
- 阿根廷：布宜诺斯艾利斯咖啡馆、探戈舞厅、潘帕斯草原
确认用户选择一种或多种风格。

### 步骤 3：调用 AI 生图
调用配置的 AI 图像生成 API，使用产品图 + 场景 prompt 生成场景图。
prompt 模板由本技能维护，包含：
- 场景背景描述（西语/葡语关键词）
- 光线和色调要求
- 美客多平台合规限制（不露脸、不夸大功效等）

### 步骤 4：批量生成多尺寸
为适应美客多各站点图片规范，批量输出：
- 主图（500×500）
- 附图（800×800）
- 素材图（1200×1200）

### 步骤 5：输出现成品
输出图片文件列表 + 每张图的适用建议（主图/附图/场景素材）。

## 失败处理
| 错误 | 处理 |
|------|------|
| 用户未提供产品图 | 引导用户上传或从美客多 Listing 截图 |
| AI 生图 API 不可用 | 告知用户当前 AI 生图服务暂不可用，建议稍后再试 |
| 生成结果不满意 | 提供风格调整选项（更写实/更插画风/更简洁/更热闹） |

## 注意事项
- 生成图片不包含真人面部（美客多政策限制）
- 场景图不能误导消费者（如实反映产品使用场景，不可 P 图造假）
- 本技能本身不包含真实 AI 绘图后端，需要配置外部 AI 图像服务
